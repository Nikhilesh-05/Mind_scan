# Mission Statement
To develop an accessible, private, and highly accurate Multimodal Depression Detection System that analyzes text, audio, and visual cues simultaneously to provide objective mental health screening and encourage early clinical intervention.

# Problem (or) Product Description
Current clinical methods for diagnosing depression heavily rely on self-reporting questionnaires (e.g., PHQ-9) and face-to-face evaluations. These are prone to self-reporting bias, subjective interpretation, and inconsistency, often deterring individuals from seeking timely help due to cost or stigma. 

MindScan is a web-based artificial intelligence system that acts as an objective, automated preliminary screening tool. By capturing real-time user interactions—conversational chat (Text), vocal prosody (Audio), and facial expressions via webcam (Video)—the system computes a "Fusion Score" that models the holistic observation tactics of trained human clinicians. It outputs an immediate, integrated risk-assessment report (Low, Moderate, High) with personalized recommendations.

# Assumptions and Constraints
**Assumptions:**
1. End-users have access to a functional webcam and microphone.
2. The user has a stable internet connection for accessing the web interface and backend API computations.
3. Users will provide relatively natural responses and facial expressions during the 30-second recording windows.

**Constraints:**
1. The system serves only as a preliminary screening tool, NOT a definitive medical diagnosis.
2. Deep learning and computer vision tasks (such as face-api.js) must be optimized to run smoothly within a standard web browser without crashing.
3. Strict data privacy guidelines must be adhered to; raw video/audio data cannot be permanently stored on the server.

# Stakeholders
1. **End-Users (Patients/Individuals):** People seeking a private, low-barrier baseline assessment of their mental well-being.
2. **Healthcare Providers / Therapists:** Professionals who might use the generated PDF reports as supplemental background data during clinical intake.
3. **Project Supervisors:** Faculty members overseeing the technical execution and academic rigor of the project.
4. **Development Team:** The engineering student(s) designing, building, and maintaining the application.

# Worksheet / Data collection / Observation etc

- **Data Modality 1 (Text):** Captured 12 conversational turns per mock session. Observed average negative sentiment triggers tied closely to words like 'tired' and 'hopeless'.
- **Data Modality 2 (Audio):** Recorded 15-second WAV buffers. Observed stability in mock prosody extraction (Pitch Mean ~140-165Hz depending on mood state).
- **Data Modality 3 (Video):** Analyzed live webcam streams at 10 frames per second using `@vladmandic/face-api`. 
- **Observations:** Initial video models skewed toward "neutral/disgusted" for subtle expressions. An algorithmic multiplier (2.5x) was successfully applied to the "sad" emotion score to boost sensitivity and reflect accurate states without triggering false positives.
- **System Integration:** PDF generation required migrating from text-buffer tricks to genuine `fpdf2` rendering to ensure browser download compatibility. Complete end-to-end latency from submission to report generation averages < 2.5 seconds.
